[FEATURE: Multi-Cloud-Storage-Pooling] Core Feature
Combines multiple Google Drive and Mega.nz accounts into a unified virtual storage pool.

Aggregates disparate free and paid quotas into one virtual drive view. Tracks live gigabyte usage across all connected accounts in real-time.

Anchor: `src-tauri/src/rclone/account_manager.rs` -> `AccountManager::list_connected_remotes`
[FEATURE: ADB-Phone-Photo-Delta-Sync] Mobile Import
Compares phone MediaStore records with local SQLite to pull ONLY newly captured photos and videos.

Eliminates redundant multi-gigabyte copying over USB/WiFi. Automatically creates `YYYY/MM/` date folders and checks SHA-256 hashes.

Anchor: `src-tauri/src/adb/client.rs` -> `AdbDeviceManager::query_mediastore`
[FEATURE: YouTube-Private-Video-Pipeline] Video Pipeline
Automatically uploads screen recordings to YouTube as private videos assigned to specific playlists.

Saves precious cloud drive quotas. Uses HTTP resumable uploads with chunked transfer and enforces private visibility.

Anchor: `src-tauri/src/youtube/uploader.rs` -> `YouTubeUploader::upload_resumable_video`
[FEATURE: Localhost-App-Backplane-API] Inter-App Sync
Local HTTP API on port 59432 enabling custom Windows .EXE and note apps to sync state effortlessly.

Eliminates the need to bundle heavy cloud SDKs into every custom application you develop.

[TRAP: Mega-Concurrent-Node-Session-Limits] Critical Trap
NEVER bypass Rclone's connection pool to issue concurrent raw HTTP uploads to Mega.

Mega limits concurrent node tree updates. Uncoordinated parallel writes cause node sequence divergence and session invalidation.

Anchor: `src-tauri/src/rclone/supervisor.rs` -> `RcloneDaemonSupervisor::get_upload_queue`
[TRAP: ADB-Windows-CRLF-Double-Newline] Critical Trap
NEVER parse raw string output from ADB shell on Windows without stripping \r\r\n.

Windows console runtime adds extra carriage returns to Android shell outputs, causing integer byte parsing crashes.

Anchor: `src-tauri/src/adb/client.rs` -> `sanitize_adb_output`
[TRAP: YouTube-Daily-Quota-Burn] Critical Trap
NEVER poll the YouTube Data API to check video processing status in a fast loop.

YouTube gives 10,000 units/day. Video upload costs 1,600 units. Looping status polls drains the daily quota in seconds.

Anchor: `src-tauri/src/youtube/uploader.rs` -> `handle_resumable_completion`
ADB Phone Delta Import Sequence Data Flow 
sequenceDiagram
    participant UI as Desktop UI
    participant ADB as ADB Subsystem
    participant Phone as Android Device
    participant DB as SQLite Catalog
    participant Mega as Mega Photo Pool

    UI->>ADB: Scan Device Media
    ADB->>Phone: adb shell content query (MediaStore)
    Phone-->>ADB: Returns metadata (name, size, timestamp)
    ADB->>DB: Compare against synced catalog
    DB-->>ADB: Delta result (e.g. 18 new files)
    ADB->>UI: Show Delta: "18 Unsynced Photos (64 MB)"
    UI->>ADB: Click "Import Unsynced"
    ADB->>Phone: adb pull new files
    Phone-->>ADB: Stream file bytes
    ADB->>DB: Compute SHA256 & register photo records
    ADB->>Mega: Dispatch to Mega Photo Pool
